> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Extract a reusable MenuCard + MenuCardItem component pair from the Figma MenuCard design and wire it into PromptInputMenu, replacing the current inline buttons.

**Architecture:** Two components in `core/ui/menu-card.tsx` — `MenuCard` (glass overlay container) and `MenuCardItem` (action row with optional illustration, title, and description). PromptInputMenu swaps its popover content from raw `<button>` elements to the new components.

**Tech Stack:** React 19, Tailwind v4 (Domus token system), Radix Popover, Vitest + RTL.

// core/ui/menu-card.tsx
import type * as React from 'react'
import { cn } from '@/lib/utils'

function MenuCard({
  children,
  className,
  ...props
}: React.ComponentProps<'div'>) {
  return (
    <div
      data-testid="menu-card"
      className={cn(
        'flex flex-col gap-6 rounded-2xl border border-outline bg-surface-glass-heavy p-6 shadow-overlay backdrop-blur-[var(--blur-medium)] overflow-clip',
        className,
      )}
      {...props}
    >
      {children}
    </div>
  )
}

export { MenuCard }
```

Token mapping from Figma:
- `rounded-[20px]` → `rounded-2xl` (radius-2xl = 20px)
- `p-[24px]` → `p-6` (24px)
- `gap-[24px]` → `gap-6`
- `border-[#ebedf1]` → `border-outline` (semantic token)
- `bg-[var(--surface-hud,white)]` (Figma uses `/hud`) + `backdrop-blur-[8px]` → `bg-surface-glass-heavy backdrop-blur-[var(--blur-medium)]`
- `shadow-[0px_20px_80px_0px_rgba(0,0,0,0.17)]` → `shadow-overlay` (closest token)
- `overflow-clip` → kept as-is

function MenuCardItem({
  title,
  description,
  icon,
  className,
  ...props
}: {
  title: string
  description: string
  icon?: React.ReactNode
} & Omit<React.ComponentProps<'button'>, 'children'>) {
  return (
    <button
      type="button"
      className={cn(
        'flex items-center gap-3 text-left transition-colors',
        className,
      )}
      {...props}
    >
      {icon && (
        <div data-slot="menu-card-icon" className="shrink-0">
          {icon}
        </div>
      )}
      <div className="flex min-w-0 flex-1 flex-col gap-1 py-2.5">
        <span className="font-display text-2xl text-on-surface">{title}</span>
        <span className="text-body text-on-surface-muted">{description}</span>
      </div>
    </button>
  )
}

export { MenuCard, MenuCardItem }
```

Token mapping from Figma:
- `gap-[12px]` between icon and text → `gap-3`
- `gap-[4px]` between title and description → `gap-1`
- `p-[10px]` on text container → `py-2.5` (vertical only, based on Figma structure)
- Title: Kalice at 24px → `font-display text-2xl`
- Title color: `--text/primary` → `text-on-surface`
- Description: Noto Sans (body) at 14px → `text-body` (already 14px)
- Description color: `--text/disabled` → `text-on-surface-muted`
